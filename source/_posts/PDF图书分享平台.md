## 项目简介

这是一个 PDF 图书分享平台，使用 Vue 3 + Node.js + MySQL 开发。

### 技术栈

- **前端**: Vue 3 + Vite + Pinia + Vue Router
- **后端**: Express + MySQL
- **认证**: Session-based 认证

### 功能特性

- 用户注册登录
- 图书上传与下载
- 收藏与评分
- 积分系统
- 管理员后台（审核、用户管理、数据统计）
